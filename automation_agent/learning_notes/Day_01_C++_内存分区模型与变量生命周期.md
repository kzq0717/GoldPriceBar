## 📌 核心概述
> 理解 C++ 进程的虚拟内存空间划分：栈区、堆区、全局/静态存储区、常量存储区与代码段。

---

## 💡 深度技术要点
- **栈区 (Stack)：由编译器自动分配和释放，存放局部变量、函数参数，访问速度极快，空间有限（一般几MB）。**
- **堆区 (Heap)：由程序员动态分配 (new/malloc) 和释放 (delete/free)，空间大但可能产生内存碎片与泄漏。**
- **全局/静态区 (Data/BSS)：已初始化的全局/静态变量放入 .data，未初始化的放入 .bss，程序结束时由系统回收。**
- **代码段与只读数据区 (Text/RoData)：存放机器指令与字符串字面量，内存写保护。**

---

## 💻 经典精辟代码示例
```cpp
int g_val = 10;          // .data 段
static int s_val;        // .bss 段 (自动零初始化)

void func() {
    int stack_var = 5;   // 栈内存 (离开作用域自动销毁)
    int* heap_var = new int(20); // 堆内存 (必须手动 delete 或使用智能指针)
    delete heap_var;
}
```
